## 读者说了什么（转述）

Walmyr Lima e Silva Filho，[1]：

- 读了书、看了作者的演讲之后，把作者的教学方法搬到一个面向测试工程师（和少数开发者）的辅导班上，自称思路与 CS 190 类似。
- 做法：为期一个月，每周一次两小时的视频课，讲自己总结的"测试设计十四要素"（写在一篇博客里，串里没有列出是哪十四条）。配套练习是给一个 Node.js + React 的 Web 应用写自动化测试，按学员资历分初、中、高三档和一个面向 DevOps 的档。学员约五天做完，提 PR，由这位读者做代码评审；这样循环三轮，最后公布自己的参考解。
- 自述：办过三期，共 38 名学员，效果很好；鼓励学员互评但参与度低；上一期请了两位往期优秀学员帮忙评审。
